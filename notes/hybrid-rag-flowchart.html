04 · What are these models?

Dense understands meaning. Sparse remembers words.

A model is a reusable machine that transforms input into output. EmbeddingGemma is learned from data. BM25 is a mathematical ranking algorithm, not an LLM.

Dense · EmbeddingGemma

It reads the complete text and creates 768 numbers. Nearly every position has a value, so the vector is dense. Similar meanings point in similar directions.

“get around login”→EmbeddingGemma→[768 numbers]

Best at: paraphrases, concepts, and differently worded natural-language questions.

Weakness: it can miss the special importance of an exact flag, CVE, header, filename, or payload string.

Sparse · BM25

It keeps only terms present in the text. Missing terms are invisible zeros, so most possible positions are empty. Rare, repeated, focused terms get more importance.

“sqlmap --risk=3”→BM25→{term IDs: weights}
sqlmap2.8
risk2.2
injection1.6
security0.3

Best at: commands, CVEs, headers, tool names, filenames, options, and error messages.

Weakness: it does not automatically know “get around login” and “authentication bypass” mean nearly the same thing.

+
Why hybrid? Security questions contain human meaning and exact machine strings. Dense catches meaning; BM25 protects exact details; RRF lets both vote.

07 · No scary words left

glossary

Use these definitions whenever the pipeline starts to feel abstract.

Model

A reusable machine that changes input into output. EmbeddingGemma changes text into numbers.

Token

A small text piece counted by a model: a word, word part, or punctuation.

Vector

An ordered list of numbers. Search compares vectors to estimate similarity.

Embedding

A vector made from text. It is a search fingerprint, not a written summary.

Dense vector

Nearly every position has a number. It represents overall meaning.

Sparse vector

Only terms present in the text have non-zero values. It represents vocabulary.

BM25

Keyword ranking using term frequency, rarity, and document length.

Cosine similarity

Compares dense-vector direction. Similar direction usually means similar meaning.

RRF

Reciprocal Rank Fusion. Results near the top of either list receive votes.

Qdrant point

One database record containing named vectors and a JSON payload.

Payload

Labels returned with a hit: text, title, pages, IDs, and flags.

Top-K

Return only the best K matches, such as the best eight chunks.

Parent

The complete detected section. It gives broad surrounding context.

Child chunk

A small part of a parent used as a precise search target.

Metadata

Information about the text: page, title, document ID, year, and source.

Final truths to remember

✓PyMuPDF creates the first visual blocks. It does not understand the security topic.
✓Section detection groups block IDs between headings. It does not replace extraction.
✓Chunking makes sections small enough to search. Parents preserve larger context.
✓Children are primary search points. Parents normally stay in a lookup store.
✓Dense and sparse are two representations of the same child, not two new documents.
✓The agent does not fetch every chunk. Retrieval returns a small ranked set.
